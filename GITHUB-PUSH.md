# Публикация в GitHub

1. На GitHub создайте публичный пустой репозиторий `tz-12-konditerskaya-saharnyy-ceh` без README/license.
2. Откройте терминал в папке проекта и выполните, заменив `<ваш-логин>` на свой логин:

```bash
git remote add origin https://github.com/<ваш-логин>/tz-12-konditerskaya-saharnyy-ceh.git
git push -u origin main
```

Локальная история содержит 10 содержательных коммитов. После push заполните About, Website (после Vercel) и Topics: `google-analytics`, `utm`, `apps-script`, `manychat`, `datalens`, `vercel`. Push не выполнялся, поскольку доступ к вашему аккаунту GitHub не подключён.
