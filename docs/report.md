# Аналитическая записка

## Цель
Связать источник перехода, взаимодействия на сайте и заявку.

## План теста
1. Открыть опубликованный сайт по UTM-ссылке.
2. Проверить сохранение меток между страницами.
3. Отправить заявку с датой минимум через 3 дня.
4. Проверить строку в `leads` и поля UTM.
5. Проверить событие в GA4 DebugView/Realtime.
6. Построить Traffic acquisition, Explore funnel и DataLens.

## Результаты
Фактических данных подключённых GA4, Sheets и DataLens на момент подготовки нет. Конверсии и лидирующий канал не указываются до тестирования.

## Ограничение
`fetch` в режиме `no-cors` не позволяет читать ответ Apps Script из браузера; подтверждать успешность следует по реальной записи в таблице.
