# Подключение GA4 и формы

## GA4
1. В `js/analytics.js` замените `G-XXXXXXXXXX` на настоящий Measurement ID.
2. В ресурсе GA4 включите Enhanced measurement в веб-потоке.
3. Отметьте ключевыми событиями только `generate_lead`, `contact_click`, `messenger_click`.
4. Зарегистрируйте семь пользовательских параметров из `docs/events.md`.
5. Проверьте события в DebugView и сохраните реальные кадры в `screens/ga4/`.

## Google Таблица и Apps Script
1. Создайте Google Таблицу для заявок.
2. В Apps Script вставьте код из `apps-script/Code.gs`. В настройках проекта → Script Properties добавьте `SPREADSHEET_ID` со значением ID таблицы.
3. Запустите функцию `setupSheet()` из редактора Apps Script, подтвердите разрешения и убедитесь, что создан лист `leads`. В нём задаются заголовки, список статусов и условное форматирование.
4. Deploy → New deployment → Web app. Выполнение — от имени владельца; доступ — для всех, у кого есть ссылка, если это разрешено правилами учебного аккаунта. Скопируйте URL `/exec`.
5. В `js/form.js` укажите URL в строке `window.SAHARNY_APPS_SCRIPT_URL = window.SAHARNY_APPS_SCRIPT_URL || '';`. Не добавляйте URL с персональными данными или секретами.
6. Выполните тестовую заявку через опубликованный сайт. Проверьте запись в `leads`, UTM-поля и статус `new`. Повторный `request_id` не должен создавать вторую строку.

## Важная проверка CORS
Форма использует `fetch` и ожидает JSON с `ok: true`, поэтому `generate_lead` отправляется только после прочтения успешного ответа. Если браузер сообщает CORS-ошибку, сначала проверьте, записалась ли строка в таблицу; не объявляйте заявку успешной только по факту нажатия кнопки. Исправление CORS нужно проверить в браузере после публикации веб-приложения, поскольку его поведение зависит от настроек Google Workspace.

## Безопасность и данные
- Не передавайте в GA4 имя, телефон, e-mail, комментарии, request_id и полный URL с данными формы.
- Apps Script проверяет телефон, e-mail, артикул, вес, дату, ярусы, согласие, длину текстовых полей и дубли.
- До сдачи проверьте дату с запасом не менее трёх дней и протестируйте некорректный телефон — ожидается `form_error`.
