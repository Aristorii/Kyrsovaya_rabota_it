## Реализовано в комплекте
- 9 статических страниц: главная, каталог из 20 моделей, конструктор, начинки, калькулятор порций, контакты, спасибо, политика конфиденциальности, 404.
- Адаптивный интерфейс, брендовые цвета `#D1567A`, `#FFF5EE`, `#4A2E2A`, `#9FD8C5`.
- Расчёт цены, порций и предоплаты; UTM в sessionStorage; заготовка событий GA4.
- Apps Script для валидации и записи заявок в лист `leads`.
- Документация, схема, реестр UTM, презентация PDF/PPTX.

## До сдачи обязательно
1. Вписать настоящий Measurement ID GA4 и проверить DebugView.
2. Создать Google Таблицу, задать `SPREADSHEET_ID`, развернуть Apps Script и подключить URL.
3. Проверить реальную заявку с UTM и строку в листе.
4. Опубликовать на GitHub/Vercel и обновить ссылки.
5. Настроить ManyChat в своём Instagram и создать DataLens на реальных данных.
6. Добавить настоящие кадры доказательств; не указывать вымышленные показатели.
