# С чего начать

## 1. Открыть сайт локально

Самый простой вариант — открыть `index.html` двойным щелчком. Для более точной проверки в VS Code установите расширение **Live Server** и выберите `Open with Live Server`.

Страницы проекта: `index.html`, `cakes.html`, `builder.html`, `fillings.html`, `guests.html`, `contacts.html`, `thanks.html`, `privacy.html`; страница ошибки — `404.html`.

## 2. Что уже работает в интерфейсе

- Каталог из 20 карточек с фильтром по четырём категориям.
- Открытие карточки в модальном окне.
- Расчёт цены и предоплаты в конструкторе, проверка минимального веса для двух ярусов.
- Калькулятор веса по количеству гостей.
- Фильтры аллергенов и кнопка копирования `SWEET5`.
- Валидация формы, согласие, дата не раньше чем через 3 дня.
- Сохранение UTM-меток в `sessionStorage` и перенос их в скрытые поля формы.

## 3. Что нужно подключить отдельно

- В `js/analytics.js` указать настоящий Measurement ID ресурса GA4.
- В `js/form.js` указать URL развернутого веб-приложения Apps Script. Пока URL пустой, форма специально сообщает, что работает в демо-режиме, и не утверждает, что заявка записана.
- Создать Google Таблицу, указать `SPREADSHEET_ID` в свойствах Apps Script и выполнить реальную тестовую заявку.
- Проверить состав и аллергены по технологическим картам: подробные рецептуры и КБЖУ в исходном ТЗ отсутствуют.
- Заменить CSS-иллюстрации тортов реальными фотографиями, если компания их предоставит.

## 4. Публикация

Инструкция для GitHub: `GITHUB-PUSH.md`. После создания публичного репозитория подключите Vercel к ветке `main` и добавьте адрес сайта в README и поле Website GitHub.

> Важно: репозиторий в архиве содержит локальную историю Git. Не удаляйте папку `.git`, если хотите сохранить подготовленные коммиты.
